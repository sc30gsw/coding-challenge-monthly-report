# コメントは報告書の内容ではないので、確定後も追加できる

コメントは 1 テーブルで表し、`report_id` を必須、`line_id` を null 可とします。明細に対するコメント（差し戻しの指摘が主）と、報告書全体に対するコメント（「今月は全体的に〜」）の両方が実在するため、テーブルを分ける理由がありません。

**確定済み Report にもコメントは付けられます。** ADR-0008 の不変性は「取引先に提出される中身」に掛かる制約であり、やりとりの記録はその中身ではありません。確定後に誤りを見つけた人が経緯を残せないのは、運用として成立しません。

## 影響

- 不変性の境界が「Report / ReportLine の内容」と「それに付随する記録」の間に引かれます。この線引きはコードから自明ではないので、README とスキーマのコメントに残します。
- 確定済み Report への UPDATE を拒否する DB トリガ（ADR-0008）は、comments テーブルには掛けません。
- Revision を作るとコメントは複製しません。コメントは版ごとのやりとりであり、系列をたどれば過去版のコメントは読めます。
