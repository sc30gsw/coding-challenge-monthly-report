# 取引先マスタは持つが、表紙の取引先名と宛先は報告書側にコピーする

取引先（Client）のマスタテーブルを持ち、報告書の新規作成時に取引先を選ばせます。ただし **取引先名と宛先は、報告書に文字列としてコピーして保存します**。表示のたびにマスタを FK で引き直すことはしません。

[0008](./0008-immutability-enforced-in-two-layers.md) で「確定後は中身が変わらない」と宣言した以上、マスタ側の変更が確定済み報告書の見え方を変えてはいけません。取引先が社名変更しただけで、過去に提出済みの報告書の取引先名が書き換わるのは、不変性の一番わかりにくい違反経路になります。宛先（担当者名など）も同じ理由でコピーします。

## 影響

- マスタは新規作成時の入力補助と、一覧の絞り込みに使います。表示の正は報告書側のコピーです。
- `client_id` は FK として残します（系列や取引先単位の集計に要ります）が、名前の表示には使いません。
- マスタを直したときに既存の下書きへ反映されません。これは意図した挙動なので、必要なら下書き側で手直しします。
